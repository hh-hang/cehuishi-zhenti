# 注册测绘师在线题库

注册测绘师历年真题与模拟题在线答题、判分和练习。

## 在线答题

[打开在线题库](https://hh-hang.github.io/cehuishi-zhenti/)

## 考试科目

- 测绘综合能力
- 测绘管理与法律法规
- 测绘案例分析

## 项目结构

```text
.
├── index.html      # 网站首页
└── exams/          # 各科目的真题与模拟题页面
```

## 试卷命名

- 历年真题：`科目-年份.html`
- 模拟试卷：`科目-模拟题-编号.html`

运行 `node scripts/generate-catalog.mjs` 后，试卷会自动显示在首页对应分区。
